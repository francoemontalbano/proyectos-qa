# QA Test Repository - Buscador Provinciano

## Descripción y Alcance
Repositorio de documentación de testing para "Provinciano", el buscador de datos geográficos de Argentina de Proyecto Nahual. El plan de pruebas abarca la validación funcional de filtros combinados, criterios de ordenamiento en grilla y control sintáctico de cadenas.

## Archivos Incluidos
- `Test Case - Provinciano - Franco.csv`: Matriz de diseño de casos de prueba exhaustivos.
- `Bugs - Provinciano - Franco.csv`: Reporte detallado de defectos e inconsistencias críticas de la interfaz y ordenamiento.
